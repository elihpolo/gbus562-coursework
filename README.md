# GBUS 562-coursework

## About

This repository is for my GBUS 562 AI Language Models course. I'm currently working toward my MS in AI in Business, and I'm looking forward to getting more hands-on experience using AI tools like Claude Code and learning how I can apply these tools in everyday life and at work.

## Weekly Work

1. Week 1: I used Claude Code to build a UMW themed Tic-Tac-Toe game with two game modes single-player and two-player. The game also has three difficulty levels and a scoreboard.
2. Week 2: I used Claude Code to build a browser-based Prompt Lab, then used it to test four prompting techniques on tasks for Wildframe Coffee Roasters. The project includes a writeup and the exported conversations.
3. Week 3: a RAG tool that answers questions from Copperline Manufacturing's finance documents, built with Claude Code.
